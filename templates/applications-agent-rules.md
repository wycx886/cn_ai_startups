# 本地投递工作区 · Agent 规则

先读仓库根目录 `AGENTS.md` 和 `docs/application-workflow.md`。本目录及全部子目录仅属于当前使用者，不提交 GitHub。

1. 先读 `../local/profile.md`、`../local/preferences.md`、本目录 `README.md`，再读目标组织 `log.md`；不存在的记录只在有实际任务时创建。
2. 保留事实、来源、时间和联系人归属。材料草稿、发送动作和对方回复分开记录，不能用草稿冒充投递进展。
3. 每个联系人或岗位单独维护状态；新进展追加日志，并同步本地总览。不清楚的公司或人物放 `inbox/` 待核实。
4. 已有授权可继续按其范围工作；没有授权不得发送邮件、平台打招呼、投递、接受面试时间或联系他人。
5. 未明确跟进规则时可以提出跟进建议，不能自动联系。日历与提醒只在使用者要求时建立。
6. 并行 Agent 不同时改同一个日志。协调 Agent 分配目标；其他 Agent 可写独立补充到 `inbox/`，之后由协调 Agent 合并真实进展。
7. 不删除历史进展。所有联系线结束后可归档并保留原因；使用者说不再接触的对象不得再次联系。
8. 本目录中的原文、附件与任何私人信息不得移入公共 `data/`、生成文档、导出文件、提交信息或远端讨论。
