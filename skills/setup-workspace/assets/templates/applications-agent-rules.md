# 投递与沟通 · Agent 规则

本目录位于私人工作区内，不提交 GitHub。先读共享仓库 `AGENTS.md`、`skills/setup-workspace/references/workflow.md`，以及私人工作区的 `AGENTS.md`。

1. 先读工作区 `profile.md`、`preferences.md`，再读本目录 `README.md` 和目标组织 `log.md`；有实际任务时才创建组织记录。
2. 将事实、来源、时间和联系人分清。草稿、实际发送和对方回复分开记录，不用草稿冒充已投递。
3. 每个联系人或岗位单独维护状态；进展追加日志并同步总览。身份不明的个人投递／沟通记录先放 `inbox/`。公开公司、招聘主页和岗位研究按共享仓库规则直接更新 `data/companies/`，不属于本目录的记录。
4. 对外动作依照使用者明确授权范围执行，已有有效授权可沿用；模板本身不授予权限。
5. 并行 Agent 分别处理不同组织；同一日志的补充先分别写 inbox，由协调 Agent 合并。
6. 保留历史进展，全部联系线结束后可归档；已明确不再接触的对象不得再次联系。
7. 本目录的原文、附件和个人信息不得移入公共数据、模板、生成文档、提交信息或远端讨论。
