## 记录规则

- 一家组织一个稳定目录名，优先沿用公共资料的 `id`；多个岗位或联系人分别跟踪。
- 收到真实进展后追加公司日志，同时更新本表。草稿不是已发送，查看岗位不是已投递。
- 有一个联系人拒绝，不自动认定整家机构结束。避免重复联系同一人申请同一岗位。
- 不知道公司身份时先记入 `inbox/`，核实后再归档，不能猜公司或联系人。
- 记录、附件、聊天、薪酬和私人评价只留在此目录；不要复制到公共 JSON、Markdown、提交信息、Issue 或 PR。
- 本地规则见本目录 `AGENTS.md`，公共规则见仓库根目录 `AGENTS.md`。
