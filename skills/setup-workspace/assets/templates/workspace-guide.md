# 本人的私人工作区

此目录仅属于当前使用者，由共享仓库的 `.gitignore` 排除。所有个人事实和进展在这里维护，不另外创建第二套档案。

- `profile.md`：本人的事实基准，未知项待填写。
- `preferences.md`：本人的目标、约束与明确授权范围。
- `resume/`：本人简历构建代码、附件与生成文件。
- `applications/README.md`：本人投递和沟通总览；每家组织一个日志。
- `drafts/`：个人材料与联系草稿。
- `research/inbox/`：待核实的研究采集批次。
- `tmp/`：临时文件。

先读共享仓库 `AGENTS.md` 和本目录 `AGENTS.md`。公共研究维护在共享仓库 `data/`，个人事实和进展只写本目录。不要将个人资料复制到共享模板、公共 JSON 或提交信息中。
