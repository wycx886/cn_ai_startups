# 私人工作区 · Agent 规则

本目录是当前使用者唯一的个人资料与进展入口，不上传共享仓库。先读取共享仓库的 `AGENTS.md`，再按下列规则工作。

1. `profile.md` 是个人事实基准，`preferences.md` 是本人方向与约束；未知事实保留待确认，不用岗位要求推断经历。
2. 简历代码、附件和生成文件放 `resume/`，个人草稿放 `drafts/` 或对应组织目录；遵循本人已有的构建约定。
3. 更新进展先读 `applications/README.md`、`applications/AGENTS.md` 和公司日志，查归档及不再接触要求。
4. 每个联系人／岗位独立记录，只有真实动作或本人明确确认才能记已发送、已投递、已回复。保留发生日期、记录日期与来源。
5. 框架不自动授权对外动作；按本人明确授权范围操作。已有有效授权可沿用；只要求草稿时只生成草稿。
6. 个人新进展追加组织日志并更新总览；多 Agent 对同一个人日志的补充先分别写 `applications/inbox/`，由协调 Agent 合并。公开公司、招聘主页与岗位研究直接维护共享仓库 `data/companies/`，不使用本条私人记录流程，也不要求读取个人事实和偏好。
7. 个人原文、附件、薪酬、凭据和授权记录不得复制进共享文件、提交信息、Issue 或 PR。
