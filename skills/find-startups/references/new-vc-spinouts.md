# 新进 VC／独立投资团队识别 SOP

本 SOP 用于圈定第一波新进投资机构：已有投资平台中的投资人或团队独立形成新管理机构，可能有传统 VC、成长投资、企业投资或其他科技投资经历。这里的“新”指当前要研究的新进玩家，不要求创始人年轻，也不使用统一的成立年份硬切线。

本阶段先确认谁进入名单、为什么进入及还缺什么；Layer 2／3 的采集和实际 pitch 留给后续任务。

## 1. 发现候选

从原基金／平台团队变动、本人公开介绍、新机构公告、基金首关或被投机构融资披露寻找线索。先查已有别名、ID 和团队，避免同一机构更名、同名机构或多只基金重复建档。

候选需要回答：

- 当前机构叫什么，运营主体或品牌有什么明确依据？
- 谁发起，原来在哪些机构、承担什么已公开角色？
- 何时开始独立运作？成立、登记、品牌、首关分别指什么事件？
- 当前投资策略是否覆盖任务主题（本库例如 AI／相关科技）？能否由其公开策略、具名投资或公开活动支持？

原平台有名、创始人离职、管理人完成登记，都不能单独证明新机构已募集资金、投资 AI 或取得回报。

## 2. 核实独立运作及原平台关系

优先查本人／机构公告、官方履历、被投机构公告和适用的公开登记材料，必要时用可靠采访补充并注明限制。保留前机构和当前机构关系，不因“独立运营”就声称法律分拆、完全无关联或原平台资产／基金／组合已转移。

同名机构要核对创始人、地区、官网与主体。品牌更名、老平台延续、设立新一期基金或新设 AI 小组，不自动归为本轮新进；成熟平台留待后续 find-incumbents。

## 3. 将团队历史与新机构成绩分开

`people[].previous_firms` 保留有证据的原平台，`representative_cases` 中的每笔案例写明归属与来源 ID：

- 原平台期间的案例标 `prior_firm`。
- 当前机构的案例标 `current_firm`；该字段归因到机构，不是某一只基金。
- 原机构知名项目不能自动转为新机构组合。参与项目不自动写主导，IPO 不自动写已退出，估值不写成回收现金。

新 GP 可能还没有成熟退出，或尚无公开具名持仓。只要独立形成、团队背景和与任务主题匹配的实际策略有证据，仍可进入第一波寻源；不能把缺少退出记录等同于没有价值，也不编造收益来补齐模板。

## 4. 做第一波标记

| 标记 | 使用情形 |
| --- | --- |
| `player_group: new_entrant`、`wave: first` | 当前独立新机构与研究方向有来源支持，可列为第一波候选 |
| `wave: watchlist` | 主体、独立运作、主题方向或证据交叉存在重要缺口，说明待补内容 |
| `player_group: incumbent`、`wave: later` | 成熟平台延续或已有机构的团队／业务机会，留待后续 |
| `player_group: unresolved` | 尚不能可靠区分新进与已有，不强行纳入第一波 |

`rationale` 说明判断，`source_ids` 关联该记录的证据，`labelled_at` 记录本次编辑时间。不要改旧事实或把旧来源的 `checked_at` 刷成分类当天。

第一波和原 `coverage.role` 分开：某机构可以在寻源名单中，同时保留原资料的观察或相邻范围限定。这不是基金收益排名，也不证明适合所有使用者。

## 5. 输出与下一阶段交接

正式记录保存在 `data/companies/`，由统一索引和第一波阅读版展示。交接至少保留：机构 ID、当前名称、创始团队、原平台、独立形成口径、与研究主题匹配的方向、当前机构案例与缺口、第一波理由和证据。

后续渠道 Agent 根据名单逐项核对公开入口，不预设某个城市、岗位、投资机构或模型工具优先。私人 pitch 目的、联系人对话和跟进记录从使用者工作区读取并保存在那里。
