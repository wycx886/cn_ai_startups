# 示例：中国已有玩家，主题可选 AI

本文件是通用 `find-incumbents` 的可选地区／主题附录。只有任务指定中国、AI 或相关范围时才采用；不将中国、AI、互联网、上市或固定成立年份写成基础 Skill 的必要条件。示例核查日期：**2026-10-31**。

通用来源方法见 [研究方法](research-methods.md)；集团与业务单元、实验室及拆分关系见 [组织关系方法](corporate-ventures.md)。

## 先界定“已有”和“头部”

Incumbent 是相对于指定市场的已有玩家。成立久、公司大、已上市、模型已备案，分别只能说明某一方面，不能单独证明它是当前主题的领先者。

先确定任务的地域、行业、主题、研究截止日和研究单位。如果任务要求“头部”，先约定可比较的口径，例如特定行业的收入、客户／部署规模、市场份额或产品覆盖；写明数据期间、市场定义及来源。没有统一指标时，输出“已有玩家候选”，不用自制总分代替排名依据。企业官网自述的领先地位和性能比较保留为自述，不提升为独立评价。

当前中国机会研究可以互联网为主，按覆盖组扩展，而不是只搜索熟悉的 BAT：

| 覆盖组 | 排查方向 | 需分开的口径 |
| --- | --- | --- |
| 互联网／数字平台 | 腾讯、阿里、百度、字节及其他内容、交易、服务平台 | 集团、云业务、具名产品和研发单元不重复计数 |
| 软件及成熟技术供应商 | 企业软件、语音、视觉、数据与模型供应商 | 原行业地位与当前主题能力分别核实 |
| 云与计算基础设施 | 云服务、数据中心、服务器与网络 | 不能将所有大平台统一称为 hyperscaler |
| 芯片、硬件与消费终端 | AI 芯片、设备、手机和其他终端 | 芯片、服务器、终端、操作系统与模型是不同角色 |
| 电信与专业服务 | 运营商、专业子公司、研究院 | 集团规模不等于某个具体团队的能力或机会 |
| 汽车、工业及其他垂直行业 | 智能汽车、制造、家电、金融、医疗等 | 技术供应商、对外服务方和内部应用者分别标注 |

这些是编辑性的排查方向，不代表每家企业都已经有符合主题的业务，更不保证存在岗位。

## 从底表到具体业务证据

1. 先读 [data/platforms.json](../../../data/platforms.json) 或 [生成阅读版](../../../data/views/platforms.md)，核对已有别名和 ID。底表是发现入口；可包含有明确范围限定的主题证据，仍不等于正式机构目标、机会清单或排名。
2. 通过最新官方年报、交易所披露、IR 和公司介绍确认集团／法人身份、持续经营业务及适用规模口径。注册、品牌、控股和当前运营关系分开。
3. 如果本次主题是 AI，查找具名产品、研究单元、官方论文／代码、持续服务或具体部署；只看到一次合作、宣布接入某模型或集团宣传口号，先留线索，不宣称具有实质领先能力。
4. 将对象标为主题技术供应商、基础设施供应商、产品／服务提供方或行业应用者等实际角色。成熟行业集团使用 AI 可以具有研究价值，但不因此成为通用模型供应商。
5. 下钻到实际承载业务的法人、业务群、实验室、产品或团队。集团层面存在某主题业务，不能推出每个部门都相关；同一产品、模型与团队也不自动建成多个独立目标。
6. 新形成的创业、孵化或拆分单元可交接 `find-startups`；成熟常规业务继续由 `find-incumbents` 研究。一个母平台是已有玩家，不决定其所有单元都必须具有相同标签。

## 行业图谱、登记与报告怎么用

- [国家网信办已备案／登记信息公告](https://www.cac.gov.cn/2024-04/02/c_1713729983803145.htm)：直接读取。原公告为 2024-04-02，附件持续更新；本次页面列到 2026 年 8 月附件。可发现模型与服务运营主体，需记录实际附件版本；备案不代表排名、能力认证、市场完整覆盖或当前招聘。
- [清华电子系与中国信通院联合发布《具身智能发展报告（2026年）》](https://www.ee.tsinghua.edu.cn/info/1076/5406.htm)：直接读取，页面发布于 2026-10-17。可参考基础软硬件、产品／技术服务、行业应用等产业角色，并据此寻找具体对象；报告所载范围和统计日期不能省略。
- [中国信通院《人工智能发展报告（2024年）》](https://www.caict.ac.cn/kxyj/qwfb/bps/202412/P020241210548865982463.pdf)：本次读取到官方检索内容；报告版本为 2024 年，准确页面公开日未核。可作为历史分类框架，不将其中企业或状态当成最新现状。
- [《具身智能产业图谱（2025年）》发布说明](https://www.ncsti.gov.cn/kjdt/yqdy/yqdt/202510/t20251011_221529.html)：政府网站发布于 2025-10-11，本次读取官方检索内容。说明其由 AIIA 工作组编制，含企业自主报名与审核口径；适合发现线索，不因未收录而判断企业不存在或不重要。已有更新报告时保留版本差异。

这些来源的本次核查日期同为 2026-10-31。图谱负责扩展候选，登记可帮助核对运营主体，年报／官方业务资料核实具体事实；三者的功能不能相互替代。它们都不自动授权采集 Layer 2／3、发消息或投递。
